我们关注什么

流处理与数据系统

围绕流式计算、状态管理与数据基础设施展开系统研究与工程实现。

推理系统与运行时

关注 LLM inference runtime、serving、调度与系统级优化。

SAGE 主线框架

SAGE 是团队当前的核心框架，用于承载 stream-first 的推理系统能力。

Benchmarks 与评测

同时建设面向 ToolUse、RAG、Refiner、数据库与近似计算的评测基准。

开放协作

通过 GitHub profile、Issue、PR 与文档站公开协作，保持项目入口清晰。

学生培养与合作

欢迎研究合作、工程合作、开源贡献与学生交流。
